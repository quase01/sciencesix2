1. 실행 방법

개발본: sciencesix2/index.html을 Edge 또는 Chrome에서 엽니다.
index.html과 같은 폴더의 JS, CSS, 캐릭터 PNG 및 props 폴더가 함께 있어야 합니다.

배포본: sciencesix2/dist/불꽃연구소-단독실행.html
이 HTML 하나만 복사해서 열 수 있습니다. 스크립트, 스타일, 이미지 45개를
포함하며 크기는 약 7.70 MB입니다. 게임 실행에 서버나 인터넷이 필요하지 않습니다.

캐릭터 선택 → 탐험 시작. 방향키/WASD로 이동, E로 조사합니다.
각 미로의 점 세 개가 표시된 수상한 벽 옆에서 E를 누르면 선택 탐구실로 들어갑니다.
탐구실 안에서도 방향키와 화면 버튼으로 이동하고 장치 옆에서 E로 조작합니다.
왼쪽 아래 출구 또는 ‘연구소로 돌아가기’ 버튼으로 언제든 돌아올 수 있습니다.
R은 파이어봇 탐지입니다. 첫 스테이지 완료 후 사용할 수 있습니다.

2. 수정 전 구조와 보존한 기능

기존 index.html의 6개 스테이지, 학습 기록 모듈, characters.js 및
characters.css를 조사했습니다. props에는 실제 Blender PNG 43개가 있습니다.
대부분 192×192 셀 두 개를 가로로 연결한 전후 상태 시트이며, 혼합 실험대는
384×192 셀 두 개, 1구역 재료·열쇠는 단일 셀입니다.

기존 구현은 투명 여백을 포함한 시트를 주로 48×48로 그렸으며 캐릭터를
오브젝트보다 나중에 그렸습니다. 학습 기록은 메모리에만 보관했습니다.
원본 시작 화면에서 실행 오류와 이미지 누락은 발견되지 않았습니다.
기존 걷기 테스트 8개도 통과했습니다.

보존 사항:
- 1~6스테이지의 필수 학습 문제와 실험 순서
- 기존 28개 학습 문항 목록: 백업과 문자열 비교로 동일함 확인
- 교사용 개인 JSON, 개인 CSV, 학급 JSON 불러오기·학급 CSV
- 최종 인증서 PNG 저장
- 남녀 캐릭터 선택, 네 방향 좌우 발 교대 걷기
- 기존 Blender PNG, .blend, props/source 원본 전체
- 기존 스테이지별 색상·바닥·벽·안개·카메라·미니맵

수정 전 코드 백업: backups/pre-rpg-20261026/
index.html, characters.js, characters.css를 보관했습니다.

3. 그래픽과 충돌 개선

- PNG의 실제 알파 영역을 측정하여 prop-metadata.js에 프레임별 경계를 저장했습니다.
- world-renderer.js에서 종횡비를 유지하며 바닥 접점에 맞춰 그립니다.
- 재료, 넓은 실험대, 연구 장치, 파이어봇에 서로 다른 적정 크기를 적용했습니다.
- 그림자와 바닥 기준 Y 정렬을 사용하여 벽·장치·캐릭터·파이어봇의 앞뒤를 정합니다.
- 장치의 투명 이미지 여백과 이동 충돌 영역을 분리했습니다.
- 고정 장치 칸에는 진입하지 않으며, 주변에 작은 접근 공간을 확보했습니다.
  구역을 나누는 차단벽 열은 보존하여 잠긴 문을 우회하지 못하게 했습니다.
- 필수 장치는 금색 마름모, 보조 자료는 회색 점으로 구별합니다.
- 가까운 장치에는 바닥 강조와 E 표시가 나타납니다.
- 성공·오답에 따른 효과음, 파이어봇 반응, 기록 획득 알림을 연결했습니다.
- 이미지가 로드되지 않으면 기존 도형 장치와 기본 연구원으로 계속 플레이합니다.

4. 선택 탐구와 과학 도감

스테이지마다 비밀 탐구실 하나씩, 총 6개를 추가했습니다.
기존 미로의 수상한 벽에서 들어가는 별도 Canvas 공간입니다.
필수 문제를 바꾸지 않고, 지도 안의 장치를 직접 조작하도록 구성했습니다.

1구역: 풍선 압력 스위치
밀가루/탄산수소 나트륨을 선택하고 식초 혼합 장치를 작동시킵니다.
기체 발생 → 풍선 팽창 → 압력 스위치 → 기록실 차단문 개방을 관찰합니다.
이 혼합 반응과 연소를 구별하는 설명이 있습니다.

2구역: 거울 반사
두 거울을 E로 회전합니다. 실제 격자 경로를 따라 반사광을 계산해 표시하고,
빛이 센서에 닿으면 문을 엽니다. 전기 광원과 연소의 차이도 안내합니다.

3구역: 산소 배관
직선/굽은 배관 세 개를 돌립니다. 입출구가 서로 연결되는지 탐색하고,
공급원에 이어진 부분만 빛납니다. 초까지 연결되면 불꽃 변화와 문 개방을 표시합니다.
기존 필수 밸브 문제와는 별개의 장치입니다.

4구역: 가상 온도·산소 제어
물질 A/B가 서로 다른 가열 단계에서 점화되는 것을 관찰합니다.
산소 밸브 차단 또는 냉각으로 연소 조건을 제거하면 미션을 완료합니다.
수치 단계는 개념 모형이며 실제 온도를 의미하지 않습니다.

5구역: 검출 증거 배치
염화 코발트 종이와 석회수의 반응 카드를 모읍니다.
들고 있는 카드를 바꾸어 물/이산화 탄소 분석대에 배치합니다.
틀린 배치는 카드를 잃지 않고 다시 바꿀 수 있습니다.

6구역: 미래 생태계 전망
교통·에너지·재사용 활동을 켜고 끄며 예시 배출 지수를 비교합니다.
배출 감축 정도에 따라 식생·산호의 미래 전망 그림이 변합니다.
40 이하의 목표를 달성하면 기록실과 탐구 인증을 얻습니다.
예시 지수는 실제 배출량 계산이 아니며, 즉시 생태계 회복을 뜻하지 않는다는
설명을 화면에 명시했습니다.

과학 도감: 혼합, 빛과 열, 산소, 연소의 세 조건, 발화점, 생성물, 생태계의
7개 카드. 필수 문제 정답 또는 선택 탐구 기록 수집으로 발견할 수 있습니다.
모두 발견하면 탐구 박사 배지가 표시됩니다.

5. 파이어봇·UI·저장

파이어봇은 실제 guide-robot.png를 사용하며 플레이어가 지나온 칸을 순서대로
따라옵니다. 연구소와 선택 탐구실 모두에서 동행합니다.
대기, 이동, 조사, 기쁨, 놀람, 힌트 상태를 표현합니다.

각 스테이지 완료 보상:
1 근처 장치 탐지 / 2 탐지 범위 확대 / 3 숨겨진 장치 감지 /
4 위험 구역 경고 / 5 미수집 과학 기록 감지 / 6 최종 탐험가 배지
탐지는 위치·방향 안내이며 과학 문제의 정답을 알려 주지 않습니다.

공통 도구 모음: 도감, 파이어봇 성장 기록, 탐지, 정보 접기, 지도 확대, 저장 관리.
정보를 접어도 현재 목표는 상단에 유지됩니다.
기존 미니맵 토글은 유지하고, 공통 확대/축소를 추가했습니다.
모든 팝업에서 이동을 차단하고, 입력창에 이름을 쓸 때 게임 단축키가 작동하지 않게 했습니다.
선택 탐구실에는 키보드 포커스 순환 및 배경 입력 차단도 적용했습니다.

자동 저장 키: firelab-adventure-v2 / 버전 2
저장 내용: 현재 구역, 방문한 구역의 전체 게임 상태·지도, 재료·열쇠·씨앗,
필수 미션, 학습 답변·오답, 비밀방, 퍼즐 조작 상태, 도감, 파이어봇 능력.
이름과 학습 기록은 이 브라우저의 로컬 저장소에 보관하며 서버 전송은 없습니다.
새로 열면 캐릭터 선택 후 ‘이어서 탐험’ 또는 ‘새로 시작’을 선택할 수 있습니다.
저장 관리에서 전체 진행과 이름·답변을 초기화할 수 있습니다.
브라우저 저장이 금지되면 저장 불가 안내를 표시하고 게임은 계속 실행합니다.
손상된 저장 형식은 불러오지 않습니다.

6. 검증 결과

환경: Windows, Node.js 24, Playwright Core, 설치된 Microsoft Edge(headless).
게임을 file:// 경로로 실행했습니다. 모바일은 390×844 터치 에뮬레이션입니다.
테스트는 이동 경로를 탐색하고 실제 이동·상호작용·화면 버튼으로 진행합니다.
필수 완료 플래그를 강제로 설정하지 않았습니다. 시간만 Playwright 시계로 가속했습니다.

- 기존 Node 걷기 테스트: 8/8 통과
- 필수 미션: 6/6 구역 완주, 선택 탐구 사용 없이 완료
- 문항: 기존 28개 전부 해결, 오답 13회 및 재시도 기록 확인
- 선택 탐구: 6/6 진입·조작·문 개방·보상 획득·원래 위치 복귀
- 도감: 7개 카드와 전체 수집 배지 확인
- 6개 구역의 장치 접근 경로, 벽 충돌, 닫힌 차단문 지도 확인
- 6개 구역의 파이어봇 추적, 안개·방문 기록, 팝업 입력 차단 확인
- 남녀 캐릭터와 네 방향 프레임, 짧은 이동의 발 교대 확인
- 미완료 실험·재료·열쇠 상태·오답·선택 퍼즐·이름·캐릭터 새로고침 복구
- 개인 JSON(3,834 bytes), CSV(3,694 bytes), 인증서 PNG(1,027,947 bytes) 실제 저장
- 실제 완료 기록 JSON을 교사 화면으로 불러오기 및 학급 CSV 저장
- 모바일 정보 접기·도감·터치 이동·가로 넘침 검사
- PNG 요청 전부 실패 시 캐릭터 선택과 6개 구역 시작 성공
- localStorage 쓰기 금지 및 잘못된 저장 형식 처리
- 단일 HTML에서 6개 구역 시작 성공, 외부 JS/CSS/PNG/네트워크 요청 0
- 정상 실행에서 JavaScript 및 콘솔 오류 0
  이미지 누락 시험에서는 의도적으로 실패시킨 이미지 요청 오류만 발생합니다.

테스트 결과와 화면/다운로드 산출물: tests/artifacts/
mission-results.json / bonus-results.json / persistence-results.json /

알려진 검증 범위:
실제 Android/iOS 기기 및 Safari/Firefox에서는 실행하지 않았습니다.
저장은 브라우저·기기의 저장 정책에 따르며 다른 기기로 자동 동기화되지 않습니다.
이번 버전은 구역마다 비밀방 1개이며, 고급 물리 시뮬레이션 대신 격자형 학습 모형을 사용합니다.
확인된 진행 불가 문제는 현재 없습니다.
